# agentic-resume (this repo)

This repo is a resume builder that runs inside Claude Code. People clone it
and ask Claude to set them up.

- If the person asks to set up, get started, try it, or build their resume:
  follow docs/SETUP.md step by step.
- If they ask how it works: answer from README.md in plain words.
- This repo holds code and the made-up sample person only. A person's real
  career data lives in their own project folder (made by setup.sh), never here.
- No em or en dashes in anything you write.
